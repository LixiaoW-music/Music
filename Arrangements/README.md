# Arrangements
Remixes, arrangements or other adaptations of existing musical works are published here !

## File naming convention
Most of my pdf files named according to the following convention: `{Optional:Composer}_{Name of music}_{Optional:Instrument code}.pdf`, where:<br>
- {Optional:Composer} is the original composer or interpreter of the music (may be empty when the original music is written by a group or unknown composer). 
- {Optional:Instrument code} consists of a code which lists all instruments present in the arrangement. If the code is empty, then the work is for piano solo.
