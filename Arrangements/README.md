# Arrangements
Remixes, arrangements or other adaptations of existing musical works are published here !

## File naming convention
Most PDF scores are named following the convention `{Composer}_{Title}_{Instrument code}.pdf` where the composer and instrument code are optional. 

### Composer
`Composer` identifies the composer, performer, or other original creator associated with the work.

It may be omitted when the original work is attributed to a group, has no clearly identified composer, or when including it would not be useful.

### Title
`Title` is the title of the original work or of the arrangement.

### Instrument code
`InstrumentCode` indicates the instruments used in the arrangement by concatenating the corresponding instrument abbreviations listed below.

If the instrument code is omitted, the arrangement is assumed to be for **piano solo**.

For arrangements written for a full orchestra, or for an ensemble sufficiently close to one, `Orchestra` may be used instead of listing every instrument individually.

## Instrument code list
The list below is a working convention rather than an exhaustive catalogue. Additional instrument codes may be introduced as needed.
### Woodwinds

| ---- | ---- |
| Flute | F |

| Clarinet | Cl |
